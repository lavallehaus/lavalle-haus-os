Turn on AI try-on

Uses FASHN, a try-on service. About 7.5¢ per piece. Takes a minute:

  1. Open app.fashn.ai/api and sign in.
  2. Add credits, then tap Create API key and copy it.
  3. Tap Paste my copied key below. It stays on this device only.
